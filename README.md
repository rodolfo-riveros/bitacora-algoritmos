# Bitácora de Algoritmos

Plataforma interactiva para aprender algoritmos y estructuras de datos. Cada módulo combina un **simulador visual**, el **código en Python** sincronizado con lo que pasa en pantalla, y **teoría de repaso** al final.

## Temas

- ✅ Pilas (Stack) — con Torres de Hanói integrado
- ✅ Colas (Queue) — con el juego Papa Caliente
- ✅ Listas Enlazadas
- 🚧 Tablas Hash
- 🚧 Árboles Binarios (con sus recorridos)
- 🚧 Grafos: representación y recorridos
- 🚧 Fundamentos de Algoritmos y Tipos de Datos Abstractos

## Ejecutar localmente

**Requisitos:** Node.js

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Stack técnico

React + TypeScript + Tailwind v4, con Vite. Sin backend, 100% en el navegador.
